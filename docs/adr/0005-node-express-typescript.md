## Kontekst in problem

Potrebujem majhen REST API z validacijo zahtev, preverjanjem uporabnikov ter dostopom do PostgreSQL.

## Obravnavane možnosti

- Node.js + Express + TypeScript
- Python + FastAPI

## Odločitev in utemeljitev

Backend bom razvil z Node.js, Expressom in TypeScriptom. Express zadošča za poti in middleware, TypeScript pa pomaga pri definiciji podatkov.

## Posledice

- **Pozitivne:** Isti jezik na obeh straneh in malo ogrodne kompleksnosti.
